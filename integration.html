かんたんHTML・CSS・JavaScript一括統合ツール

✨ 複数のWEBファイルを1つにまとめて配布や管理を快適に！

バラバラになっている HTML / CSS / JS ファイルを読み込み、CSSは <body> 直前に、JSは </body> 直前に自動組み込みした1本のHTMLファイルへ統合します。

  • 安心安全: ファイルはサーバーに送信されず、お使いのブラウザ内で処理されるためプライバシーも安心です。
  • 一括ドロップ対応: 3つのファイルを一気にドラッグ＆ドロップするだけで自動判別します。
