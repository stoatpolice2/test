1. ツールの特徴・構成

本ツールは、プログラミングの知識がなくてもノベルゲームを作成できるゲームエンジンです。
最低限の機能を備えたシンプルで軽量なツールとなっており、手軽にノベルゲームを制作できます。

【無料サーバーご利用時の注意点】

広告が自動挿入されるタイプの無料サーバーをご利用の場合、サーバー側が挿入する広告コードの影響で「プレビューやゲーム画面のレイアウトが意図通りに表示されない」「一部演出タグ（文字色指定など）が正常に表示されない」といった不具合が発生する場合があります。

動作確認・運用の際は、広告非表示のサーバーや、エディタ（VS Code や PhoenixCode）のローカルプレビュー機能のご利用を推奨いたします。

【サンプル画像スペース 1：完成ゲーム画面のキャプチャ】

収録ファイルとフォルダ構成

  • index.html : ゲームのシステム本体（プレイヤーが遊ぶ画面）
  • editor.html : プレビュー付きシナリオエディタ（制作・編集用）
  • debug.html : 変数管理＆デバッグツール（テストプレイ・動作確認用）
  • scenario.txt : ゲームのシナリオファイル（テキスト編集で作品を作ります）
  • Readme.txt : 説明書ファイル
ほのかのワンポイントアドバイス！
最初から長編は作ろうとせず、まずは「会話シーン」だけ作ってみて、それから「選択肢による分岐」も入れてみて、更に「変数によるイベント分岐」も入れてみて…と徐々に制作に慣れていくのがおすすめだよ！

2. 制作・動作確認

本ツールには、ブラウザ上でシナリオを作成できる「専用エディタ」と、分岐や変数の挙動をリアルタイムで検証できる「変数管理＆デバッグツール」が付属しています。ブラウザ（Chrome, Edge等）で開いてご使用ください。

【エディタ・デバッグツール起動時の注意点】

ツールを使用する際は VS Code や PhoenixCode のプレビュー機能から開くか、ローカルサーバー経由・Webサーバーにアップロードしてご利用ください。ファイルを直接ダブルクリックして開くとローカルファイルのセキュリティ制限（CORS制限等）を受けるため、通信やファイルの読み込みが正しく動作しない場合があります。

専用エディタ（editor.html）の特長・機能

【サンプル画像スペース 2：editor.htmlの画面キャプチャ】
  • 画面上部（ツールバー） ボタンをクリックすることで、コマンド名やよく使う値をワンタップで入力できます。
  • 画面左側（テキストエディタ） 構文強調（シンタックスハイライト）機能付きです。@コマンド、話者名（名前:）、コメント行などが自動で色分け表示されます。
  • 画面右側（プレビュー画面） 「プレビュー再生」をクリックすると、右側のゲーム画面にプレビューが表示されます。実際にゲームを動かしながら演出やセリフのテンポを確認できます。
  • ファイルを開く すでに作成したシナリオファイル（scenario.txt）を読み込んで再編集できます。
  • scenario.txt を保存 編集が完了したら、このボタンを押すだけでゲームにそのまま読み込める「scenario.txt」がダウンロード保存されます。

変数管理＆デバッグツール（debug.html）の機能と使い方

ゲーム本体（index.html）と並べて開くことで、ブラウザ間のリアルタイム通信機能を通じてゲームの状態を外部から確認・操作できます。シナリオ後半のテストや分岐条件のチェックに活用してください。

【サンプル画像スペース 2：debug.html の画面キャプチャ】
  • 変数のパラメータ調整 変数のパラメータ（charaA、charaB、charaC）の現在値をリアルタイムに監視できます。数値入力欄から直接任意の値を設定し「反映」を押すか、「全パラメータを一括変更」でテストしたい数値へ即座に変更できます。
  • 指定シーンへジャンプ 目的のシーンIDを指定して「ジャンプ」ボタンを押すことで、シナリオの任意の場所へ一瞬で移動できます。長編シナリオの途中確認やエンディング演出のテストに最適です。
  • リアルタイムプレビュー 現在ゲーム側で表示されている「話者名」と「テキスト（演出タグを除去した純粋な文章）」が自動更新され、進行状況をひと目で把握できます。

【デバッグツールの連携手順】

  1. 「index.html（ゲーム本体）」と「debug.html（デバッグツール）」を同じブラウザで同時に開きます。
  2. デバッグツール側の「現在のシーンID」や「パラメータ」に現在のゲーム状態が自動で反映されます。
  3. パラメータを書き換えて「反映」ボタンを押したり、シーンIDを指定して「ジャンプ」を行うと、ゲーム本体側が即座に同期して表示が切り替わります。
ほのかのワンポイントアドバイス！
複雑な分岐を作るときは、デバッグツール（debug.html）を使ってパラメータを書き換えながらチェックするとテストプレイがすっごく楽になるから試してみてね！

3. シナリオファイル（scenario.txt）の書き方ルール

scenario.txt には「会話文」と「演出用コマンド（@から始まる行）」を記述します。

@bg: images/bg01.webp
@bgm: sound/sound01.mp3
@character: images/honoka.webp|pos:center
ほのか:こんにちは！『ノベルゲーム制作ツール』へようこそ！

目が覚めると、見知らぬ部屋にいた……。
# ここはコメント行です（ゲーム内には表示されません）

基本のルール

  • 話者名とセリフ：話者名とセリフはコロン「:」で区切ります。（例：ほのか:こんにちは！）
  • 地の文：「:」がない行は、話者名なしの「地の文（ト書き）」になります。（例：目が覚めると、見知らぬ部屋にいた……。）
  • 演出コマンド：「@」から始まる行は、背景変更やBGM再生などのシステム命令です。
  • 文字色の指定：セリフや地の文の中で <color:色指定>強調したい文字</color> と書くと部分的に文字の色を変えられます。（例：<color:red>危険！</color>、<color:#ff9900>重要メッセージ</color>）
  • 指定の継続：指定（@bg や @character など）を省略した行は、直前の状態がそのまま維持されます。
  • コメント行：「#」または「//」で始まる行はコメント（メモ書き）となり、ゲームには表示されません。
ほのかのワンポイントアドバイス！
このゲームのプログラムは、『@から始まるコマンド行の設定を、次に現れるテキスト行の属性としてすべて蓄積する』という仕様になってるんだ。
だから@から始まるコマンド行の直後にテキスト行（セリフや地の文）がないと、プログラムが混乱して反映されなくなっちゃうから気を付けてね！

4. 演出コマンド一覧

シナリオ内で使用できる主要な演出コマンドおよび装飾タグの一覧です。

コマンド・タグ 記述例 説明
文字色の指定 <color:[色指定]>文章</color> テキスト内の特定の文字に色を付けます。
色名（red, yellow など）やカラーコード（#ff0000 など）で指定できます。
（例：<color:red>危険！</color>）
背景画像の変更 @bg: [画像パス] 背景画像を変更します。（例：@bg: images/bg01.webp）
※空文字「@bg: 」にすると背景を消去（黒画面）します。
BGMの再生・停止 @bgm: [音声パス] BGMを再生します。（例：@bgm: sound/sound01.mp3）
※空文字「@bgm: 」にするとBGMを停止します。
立ち絵表示・位置指定 @character: [画像パス]|pos:[位置] 位置（pos）は left（左）、center（中央）、right（右）から指定できます（省略時は center）。
（例：@character: images/honoka.webp|pos:left）
※空文字「@character: 」にすると立ち絵を消去（非表示）します。
画面フェード（暗転） @fade: true 直後のセリフに移動する際、黒画面を介して滑らかに切り替えます。
移動先ラベル作成 @label: [ラベル名] 選択肢の飛び先やルート分岐先の「目印」として配置します。（例：@label: happy_end）
選択肢表示・好感度加算 @choice: ボタン文章|next:ラベル名|favor:キャラ名:数値 / ... 選択肢ボタンを表示します。「/」で区切ることで複数の選択肢を作れます。
「favor:キャラ名:数値」で対象キャラ（charaA/charaB/charaC）の好感度を加減算します。
（例：@choice: ほのかと行く|next:route_a|favor:charaA:10 / 裕也と行く|next:route_b|favor:charaB:10）
変数による自動分岐 @branch: type:[モード]|... シナリオに合わせて3通りの分岐モードを使い分けられます。
・個別判定: type:single|chara:charaA|border:10|target:happy_end|else:normal_end（指定キャラの数値判定）
・最多判定: type:max|else:normal_end（一番数値が高いキャラのエンディングへ自動分岐）
・複合判定: type:multi|cond:charaA>=10,charaC>=10|target:true_end|else:normal_end（複数条件判定）
スタッフロール開始 @startCredits: true スタッフロールを開始します。
変数ってなに？
「変数」っていうのはゲーム内で変化する数値や文字を一時的に保存しておく「箱」のことなんだ！「好感度によるイベントの分岐」や、「プレイヤーが入力した名前をテキストに反映させる」など、いろんな部分で利用されるんだよ。更に詳しく知りたい人はこちらのページを読んでみてね！

5. プレイヤーが使えるシステム機能

ゲームのプレイ中、画面右上（スマホは上部）のメニューから以下の機能が使えます。

【サンプル画像スペース 3：ゲーム内システムメニューやバックログ画面のキャプチャ】
  • AUTO : 文章を自動で読み進めます。（AキーでもON/OFF可能）
  • SKIP : 一度読んだシーン（既読文章）のみを高速で飛ばします。（SキーでもON/OFF可能）
  • LOG : これまでの会話履歴（バックログ）を確認します。画面の上スワイプや上ホイールでも開けます。
  • SAVE : 最大3つのスロットにゲームの進行状況を保存します。
  • LOAD : セーブしたデータを読み込んで再開します。
  • TITLE : タイトル画面に戻ります。

6. ゲーム本体（index.html）のカスタマイズ方法

「index.html」の該当部分を直接書き換えることで、タイトル画面や演出、システム音を変更できます。

ほのかのワンポイントアドバイス！
「index.html」は「scenario.txt」とは違って独自タグは使用していないから、専用エディタよりも「VS Code」や「Phoenix Code」のようなコードエディタのほうが編集しやすいよ！
コードの中から編集したい部分を探すのは大変だから、こういったエディタに備わっている検索機能を活用しよう！

タイトル画面の文字を変更する

「index.html」内の「タイトル画面」にある以下の部分を書き換えてください。

<!-- タイトル画面 -->
<div id="title-screen">
  <h1>ノベルゲームタイトル</h1>
  <button id="start-btn" class="menu-btn">NEW GAME</button>
  <button id="title-load-btn" class="menu-btn">LOAD GAME</button>
</div>

タイトル画面の背景を変更する

「index.html」内の「タイトル画面レイヤー」にある以下の部分を書き換えてください。

/* タイトル画面レイヤー */
#title-screen {
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  background-image: url('images/bg01.webp'); /* ←ここを変更してください */
  background-size: cover;
  background-position: center;
  display: flex;
  flex-direction: column;
  justify-content: center;
  align-items: center;
  gap: 15px;
  z-index: 100;
}

スタッフロールの編集

「index.html」内の「スタッフロールデータ」にある以下の部分を書き換えてください。

img: "images/bg01.webp",
roles: [
  { role: "制作・シナリオ", name: "okojo" },
]

各種システム音の設定

タイトル画面のBGMやシステム音を編集するときは、「index.html」内の「共通定数設定」から以下の部分を書き換えてください。

// 共通定数設定
const TITLE_BGM_URL = "sound/sound01.mp3";
const ENDING_BGM_URL = "sound/ending.mp3";
const SOUND_EFFECTS = {
  click: "sound/click.mp3",
  type: "sound/type.mp3",
  select: "sound/select.mp3"
};
変数を非表示にしたいときは？
「変数はバックグラウンドでの処理のみに使いたいので画面には表示したくない」という場合は下記の方法で非表示にしてね！

好感度(変数)を非表示にする

画面左上に表示される好感度（変数）を非表示にしたい場合は以下の部分を削除してください。

<!-- 好感度・ステータス表示 -->
<div id="favor-display"></div>

セーブ・ロード画面で好感度（変数）を非表示にする

セーブ・ロード画面に表示される好感度（変数）を非表示にしたい場合は以下の部分を変更してください。

まず、updateModalSlots 関数内にある以下の行を探します。

<!-- セーブ・ロード画面に文字を表示する -->
 previewEl.textContent = `${data.speaker}: ${shortText} (${favorText})`;

この部分から (${favorText}) を削除して、以下のように書き換えてください。

<!-- セーブ・ロード画面に文字を表示する -->
 previewEl.textContent = `${data.speaker}: ${shortText}`;

⚠️「`;」まで削除しないように注意！

行の末尾にある「`;」を削除してしまうとゲームが正常に動作しなくなります。誤って削除してしまわないようにご注意ください。

7. 【応用編】UIのカラーデザインを変更する

「index.html」のスタイル定義（CSS）を書き換えるだけで、ゲーム全体の配色（UIデザイン）を一括で変更できます。

ほのかのワンポイントアドバイス！
このゲームのUIはデフォルトだと可愛い色になってるけど、シンプルなUIやかっこいいUIを使いたいときもあるよね？
そういうときは『index.html』の先頭近くにある『:root { ... }』の中身（カラーコード）を書き換えるだけで、ボタンやメッセージ枠の色がぜんぶ一緒に変わるんだ！

変更場所（index.html の先頭付近）

「index.html」をテキストエディタで開き、以下の :root 部分のカラーコードをご希望の色に書き換えてください。

:root {
  /* ベース背景色 */
  --bg-outer: #050a14;               /* 画面外側の背景色 */
  --bg-game: #0d1b2a;                /* ゲーム画面・モーダル背景色 */
  --border-game: #1b263b;            /* ゲーム画面枠線 */

  /* メインテーマカラー（ボタン・アクセント） */
  --color-primary: #ffd166;        /* ボタン背景・強調表示 */
  --color-primary-hover: #ffeea9;  /* ボタンホバー時 */
  --color-primary-text: #1d3557;   /* 主に黄系背景上のテキスト色 */

  /* メッセージウィンドウ */
  --msg-box-bg: rgba(255, 255, 255, 0.92); /* メッセージ枠背景 */
  --msg-box-border: #1d3557;        /* メッセージ枠線 */
  --msg-speaker-text: #1d3557;      /* 話者名テキスト色 */
  --msg-body-text: #2b2d42;          /* 本文テキスト色 */
}
